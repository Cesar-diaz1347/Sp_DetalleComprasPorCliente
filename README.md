Query que crea o edita un stored procedure que recibe dos parámetros: Fecha inicio y Fecha fin; evaluando si los datos recibidos son válidos.

Utiliza la base de datos de Microsoft AdventureWorks2025.

El stored procedure devuelve la lista de clientes que han realizado compras en ese rango de fechas junto con el detalle de los artículos y la dirección de entrega.
